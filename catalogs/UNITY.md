## First-use shortlist

- **A fresh Unity 6 game:** choose Universal 2D or Universal 3D in Hub; decide the render pipeline first.
- **A playable learning scene:** use the Unity 6 Create with Code units for input, prefabs, gameplay loops, and UI; keep the course asset restriction in mind.
- **A full multiplayer reference:** begin with Boss Room; for smaller isolated lessons, compare the Bitesize samples and their pinned versions.
- **Characters from Blender:** export FBX, check Unity's rig/avatar import settings, then try the Unity Registry Animation Rigging constraint sample.

## Research limits

- Live sources inspected: official Unity documentation, Unity Learn course pages, Unity Package Registry metadata, and Unity-Technologies GitHub pages/API metadata. Links show reachable evidence, not successful downloads, package installs, editor imports, project opening, or launches.
- Compatibility statements are only those the first-party pages declare; no editor or package compatibility test was performed. Treat Unity Hub's installed templates and package versions as version-specific.
- License status is not universally asserted: some repositories declare MIT or Unity Companion License, while several GitHub API records returned `NOASSERTION`. Check each linked `LICENSE.md`, third-party notices, and asset-specific terms before reuse.
