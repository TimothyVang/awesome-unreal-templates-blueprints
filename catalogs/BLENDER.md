# Blender: 20 practical research loops

[Back to the catalog](../README.md)

Each loop names a concrete first-use path and links a live first-party manual, Blender Studio resource, or official Blender Extensions listing. Evidence supports the stated use case, not every product claim. “Not checked” means this research did not verify a package download, local installation, or license; check the current extension manifest/license and your exact Blender build before adopting third-party tools.

## First-use shortlist

1. **Model a hard-surface asset:** [Blender modeling manual](https://docs.blender.org/manual/en/latest/modeling/index.html) for the built-in baseline; [ND extension](https://extensions.blender.org/add-ons/nd/) is a candidate non-destructive toolkit listed by the official Extensions directory (listing evidence only).
2. **Rig a first character:** [Rigging Fundamentals](https://studio.blender.org/training/rigging-fundamentals/) uses stock Blender; move to [CloudRig](https://extensions.blender.org/add-ons/cloudrig/) when procedural rig generation is needed.
3. **Build an asset for reuse:** [Asset Browser](https://docs.blender.org/manual/en/latest/editors/asset_browser.html) explains catalogs and link/append/pack; start with Blender Studio’s [Settlers](https://studio.blender.org/projects/settlers/) rigs and sets.
4. **Make a real-time deliverable:** [glTF 2.0](https://docs.blender.org/manual/en/latest/addons/scene_gltf2.html) documents supported PBR, mesh, and animation paths plus export caveats.
5. **Automate production rendering:** [Command-line rendering](https://docs.blender.org/manual/en/latest/advanced/command_line/arguments.html), then [Flamenco](https://flamenco.blender.org/usage/) for Blender’s render-farm workflow.

## Research evidence and blockers

- Blender manual, Blender Studio and official Blender Extensions pages cited above opened successfully. Additionally, `gh repo view` and bounded GitHub API calls confirmed KhronosGroup/glTF-Blender-IO repository metadata and its Apache-2.0 `LICENSE.txt`; no clone/download or code execution.
- Kept download/install and compatibility claims separate: no add-on was installed, and no packages were downloaded. Current support notes are from their official listings/manuals and must be checked against the exact Blender build. Blender Studio file downloads and individual reuse terms were not checked; “free” is not a license grant.
