# Godot project loops

[Back to the catalog](../README.md)

Twenty distinct first-use research loops for playable Godot projects and reusable Godot 4 recipes. Godot Asset Library pages below are the primary evidence for a listed asset's description and published version; stable documentation links support the documented workflow. A listing is not evidence that a ZIP was downloaded, opened, or run. Check each asset's current Godot compatibility and its package/source license before adopting it; the Asset Library metadata's license label is not a substitute for inspecting the distributed files.

| Loop | Use case and primary resource | Evidence and limitations |
| --- | --- | --- |
| 01 | **First playable 2D loop — Dodge the Creeps**: [Godot 4.2 demo](https://godotengine.org/asset-library/asset/2712) | Official Asset Library describes a finished avoid-the-enemies game and links it to the beginner 2D tutorial; 4.2 pin, Compatibility renderer. A small tutorial game, not a production architecture. |
| 02 | **2D platformer mechanics**: [2D Platformer Demo](https://godotengine.org/asset-library/asset/2727) | Official listing describes a complete pixel-art level with slopes, bullets, physics objects, and enemies; 4.2 pin, Compatibility renderer. Invincible player and single closed level constrain its gameplay use. |
| 03 | **3D character-controller platformer**: [Platformer 3D Demo](https://godotengine.org/asset-library/asset/2748) | Official listing identifies `CharacterBody3D` and a 3D translation of the 2D platformer approach; 4.2 pin, Forward+ renderer. | 04 | **Third-person shooter controls/combat**: [Third Person Shooter Demo](https://godotengine.org/asset-library/asset/2710) | Official listing specifies movement, aim, shoot, jump, mouse/gamepad controls, and Godot 4.5. | 05 | **Top-down action-RPG starter**: [Top-down Action RPG Template](https://godotengine.org/asset-library/asset/487) | Listing describes keyboard/touch/gamepad, moves, inventory, and quest systems; Godot 4.2, community submission. | 07 | **Host/join peer multiplayer**: [Pong Multiplayer Demo](https://godotengine.org/asset-library/asset/2798) | Official listing says one player hosts and another joins by host IP; 4.2, Compatibility renderer. LAN-style example does not imply matchmaking, relay, or internet deployment. |

| 13 | **Show a 3D scene inside a 2D game**: [3D in 2D Viewport Demo](https://godotengine.org/asset-library/asset/2804) | Official listing describes rendering a 3D robot to a custom viewport and assigning its texture to a 2D sprite; 4.2. Narrow rendering integration sample. |

## First-use shortlist

- **Fastest playable 2D baseline:** Dodge the Creeps (01), then the fuller platformer sample (02).
- **3D character/gameplay baseline:** 3D Platformer (03); TPS (04) when aiming/shooting is the core loop.
- **Multiplayer exploration:** Pong for the simplest host/join interaction (07), then WebSocket multiplayer for transport/API integration (09).
- **AI prototypes:** AStarGrid2D for tile-based movement (15); 3D Navigation for mesh path following (16).
- **Reusable project plumbing:** serialization (17), autoload scene/state (18), and editor plugins (19).
- **Blender handoff:** use the documented glTF path by default; choose direct `.blend` import only when the Blender installation requirement is acceptable (20).
