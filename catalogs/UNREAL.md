## Start here

- **2.5D gameplay:** PaperZD (01) for a compact starter; Echoes of Hubris (02) to inspect how a larger game separates its systems. Check asset and code terms before reusing either.
- **Networked character prototype:** Use PredictedMovement (09) if staying on CMC. Inspect GMASEx (08) only if already committed to GMCv2.
- **Game deploys:** Use GameLift (13) for hosted dedicated servers; use Pixel Streaming (12) when the player needs to control a rendered game instance in a browser.
- **UE 5.8 modern gameplay stack:** Pair Sample-PersistenceLab (21) for actor persistence, Foothold-Core (22) if adopting Mover traversal, and TurboSequence (23) when crowd counts exceed skeletal CMC budgets.
- **Narrative & UI architecture:** Use Inkpot (25) or SUDS (26) for text-authored branching stories; check VaCuus (27) commercial licensing vs MIT RmlUi/CommonUI before choosing an HTML/CSS HUD layer.
- **Shipping & team scale:** Enforce Gamemakin style conventions (40) early, automate plugin/project builds with UET (34), and evaluate HotPatcher (29) for differential Pak/IoStore updates.
